## 📖 About the Project

**Learn IT** is an educational mobile application developed using Flutter and Dart to make learning materials more accessible to students.

The application organizes educational resources based on students' grade levels, helping them find relevant learning content in one place.

Students can access daily notes, read subject textbooks, and submit assignments through the application.

The main goal of Learn IT is to support students in their learning journey by providing a convenient digital learning environment.

---

## 🎯 Project Objectives

- Make educational materials easily accessible to students.
- Organize learning resources according to grade levels.
- Help students access daily classroom notes.
- Provide digital access to subject textbooks.
- Allow students to submit assignments.
- Encourage independent and continuous learning.

### 📚 Grade-Based Learning Materials
Students can access learning resources according to their respective grade levels.

## ⚙️ Getting Started

Follow these steps to run Learn IT locally.

### Prerequisites

Make sure you have installed:

- Flutter SDK
- Dart SDK (included with Flutter)
- Android Studio or Visual Studio Code
- Git
- An Android emulator or physical device

### 1. Clone the Repository

```bash
git clone https://github.com/getayale/learn-it.git
```

### 2. Navigate to the Project

```bash
cd learn-it
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Check Flutter Configuration

```bash
flutter doctor
```

### 5. Run the Application

```bash
flutter run
```
